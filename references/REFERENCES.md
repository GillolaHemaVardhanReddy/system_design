# References — curated, durable sources by module

> These are canonical, long-lived resources. Links can rot; if one 404s, run `/references --refresh <topic>` in Claude Code to have Jimmy fetch a current equivalent. Jimmy adds new high-quality finds here over time.

## Cross-cutting (start here)
- **Designing Data-Intensive Applications** — Martin Kleppmann (the single best SD book). https://dataintensive.net
- **The System Design Primer** — donnemartin (GitHub). https://github.com/donnemartin/system-design-primer
- **AWS Builders' Library** — production patterns from Amazon. https://aws.amazon.com/builders-library/
- **Google SRE Book / SRE Workbook** — reliability, SLOs, incident response. https://sre.google/books/
- **ByteByteGo** — Alex Xu, SD explainers & newsletter. https://bytebytego.com
- **High Scalability** — real architecture case studies. https://highscalability.com
- **Martin Fowler** — patterns, microservices, CQRS, event sourcing. https://martinfowler.com

## A. Foundations / OS / concurrency
- **OSTEP — Operating Systems: Three Easy Pieces** (free). https://pages.cs.wisc.edu/~remzi/OSTEP/
- **Brendan Gregg** — systems performance & observability. https://www.brendangregg.com

## B. Networking
- **High Performance Browser Networking** — Ilya Grigorik (free). https://hpbn.co
- **Cloudflare Learning Center** — DNS/TLS/HTTP explainers. https://www.cloudflare.com/learning/
- **Hussein Nasser** (YouTube) — backend/networking deep dives.
- **The Illustrated TLS Connection**. https://tls13.xargs.org

## C. Databases
- **Use The Index, Luke** — SQL indexing. https://use-the-index-luke.com
- **PostgreSQL docs** (internals are excellent). https://www.postgresql.org/docs/
- **Redis docs**. https://redis.io/docs/

## D/E. Caching & Scalability
- DDIA ch. on caching/derived data · AWS Builders' Library (load balancing, caching, timeouts/retries/jitter).
